# Assistente Diário

Aplicativo web/mobile para auxiliar no dia a dia.

## Tecnologias

| Camada | Tecnologia | Pasta |
|---|---|---|
| Mobile | Ionic (Angular + Capacitor) | `mobile/` |
| Web (front end) | Angular | `web/` |
| Back end | Java + Spring Boot | `backend/` |

## Estrutura

```
assistente-diario/
├── backend/   # API REST (Spring Boot)
├── web/       # Aplicação web (Angular)
├── mobile/    # Aplicativo mobile (Ionic)
└── docs/      # Decisões, requisitos e anotações
```

## Pré-requisitos

- Git
- JDK 17 ou superior (Spring Boot 3)
- Node.js 20+ e npm
- Angular CLI (`npm i -g @angular/cli`)
- Ionic CLI (`npm i -g @ionic/cli`)
